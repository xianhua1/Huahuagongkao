## 一、项目总览

**花花公考刷题** 是一个面向国考/省考备考的在线刷题平台，核心功能包括：

| 模块 | 内容 | 数据规模 |
| ---- | ---- | ---- |
| 行测刷题 | 试卷练习、专项练习、错题本、每日一练 | 167 套卷 / 19595 题 |
| 申论刷题 | 材料阅读、格子答题卡、AI 评分 | 700 套卷 / 2907 题 |
| 备考中心 | 学习计划、报告、词库、时政、工具等 14 个页面 | 本地数据 + 实时新闻 |
| 题库管理 | 试卷/题目/申论后台管理（CRUD + 图片上传） | 管理员功能 |

前后端分离：前端 Vue3 构建后由 `server.cjs`（Node 静态服务器）托管于 :8090，并反向代理 `/prod-api`、`/exam-img` 到后端 :8080。

## 三、刷题中心

### 3.1 试卷练习 papers.vue

**文件**：`src/views/practice/papers.vue`

**功能**：展示全部行测真题卷列表，支持按**分类（省份/国考/事业编）标签**与**年份**筛选，每卷显示题数、已答数、正确率与进度条。

**核心实现**：

- 分类标签顺序固定：`CAT_ORDER` 数组（国考 → 30 省 → 北京市/上海市/天津市/重庆市/深圳市 → 事业编），首次全量拉取时从返回数据收集实际存在的分类：

```js
const CAT_ORDER = ['国考', '安徽', '福建', ..., '深圳市', '事业编']
const categories = ref([])
// 加载后：
const exist = new Set((list || []).map(p => p.version).filter(Boolean))
categories.value = CAT_ORDER.filter(c => exist.has(c))
```

- 查询通过 `listPapers({ year, version })` 调用后端 `/exam/paper/list`，筛选参数映射为后端 `ExamPaper` 字段（`version` 存的是省份分类名）。
- 每卷并发请求 `recordStats(p.id)`（`/exam/record/stats`）获取答题统计，`Promise.all` 并行填充：

```js
await Promise.all((list || []).map(async p => {
  const s = await recordStats(p.id)
  st[p.id] = s
}))
```

- 点击「开始练习/继续练习」→ `router.push('/practice/session?paperId=' + id)`。

### 3.2 刷题页面 session.vue

**文件**：`src/views/practice/session.vue`

**功能**：逐题作答主页面。支持**试卷模式**（`?paperId=`）与**随机模式**（`?mode=random&section=&count=`）。有材料的题左侧固定显示材料面板；选择选项即判分；答题卡弹窗可跳题；完成显示成绩。

**核心实现**：

1. **双模式加载**（`load()`）：

```js
if (route.query.mode === 'random') {
  const res = await randomQuestions({ section: route.query.section || '', count: route.query.count || 10 })
  questions.value = res.questions || []
  paperTitle.value = '随机练习 · ' + (route.query.section || '全部题型')
} else {
  const paperId = route.query.paperId
  const res = await getPaperDetail(paperId)       // 试卷 + 题目 + 材料
  const recs = await recordAnswered(paperId)      // 已答记录（断点续练）
  // 定位到第一道未答题
  const firstUn = questions.value.findIndex(q => !am[q.id])
  idx.value = firstUn >= 0 ? firstUn : 0
}
```

2. **选项解析**（options 为 JSON 字符串 `[{label, html}]`）：

```js
const optionsList = computed(() => {
  try { return JSON.parse(current.value.options || '[]') } catch { return [] }
})
```

3. **即时判分**（`pick()`）：点击选项 → `saveRecord({questionId, userAnswer})` → 后端返回 `{correct, rightAnswer, analysis, hasAnswer}` → 显示对错/答案/解析，答错时弹提示：

```js
const res = await saveRecord({ questionId: current.value.id, userAnswer: label })
result.value = res
if (res.correct === false) {
  const m = ElMessage({ type: 'warning', message: '答错了，正确答案：' + res.rightAnswer, duration: 2500 })
}
```

4. **答题卡弹窗**：`card-grid` 网格，按已答记录着色（绿=对/红=错/灰=未答），点击跳题：

```js
function cardClass(q) {
  const r = answeredMap.value[q.id]
  if (!r) return 'gray'
  return r.isCorrect === 1 ? 'green' : 'red'
}
```

5. **键盘支持**：`window.addEventListener('keydown', onKey)` 监听 ← → 键翻题，卸载时移除。

### 4.2 一字一格答题卡 ShenLunCard.vue

**文件**：`src/views/shenlun/ShenLunCard.vue`

**功能**：申论作答组件——按字数要求渲染 `20 列 × N 行` 的格子，每格一字，带闪烁光标与 100 字标记。

**核心实现**：

1. **布局参数**：

```js
const PER_ROW = 20     // 每行 20 格
const CELL = 36        // 格宽 36px
const GAP = 2          // 间隔
const ROW_H = CELL + GAP
// 总格数 = 向上取整到 20 的倍数（保证整行）
const size = computed(() => {
  const lim = props.wordLimit || 400
  return Math.max(PER_ROW, Math.ceil(lim / PER_ROW) * PER_ROW)
})
```

2. **隐藏输入区**：页面不可见 `<textarea>`（`left:-9999px`）接收真实输入，支持中文输入法 `compositionstart/end`：

```html
<textarea ref="inputArea" class="hidden-input"
  @compositionstart="onCompStart"
  @compositionend="onCompEnd"
  @input="onInput" @keydown="onKey"></textarea>
```

```js
function onCompEnd(e) {
  composing = false
  if (e.data) insert(e.data)   // 中文候选确认后整体插入
  inputArea.value.value = ''
}
function onInput(e) {
  if (composing) return          // 合成中不处理
  const val = inputArea.value.value
  if (val) { insert(val); inputArea.value.value = '' }
}
```

3. **插入与光标**（以字符偏移模型维护内容）：

```js
function insert(str) {
  const s = String(props.modelValue || '')
  const left = s.slice(0, cursorIndex.value)
  const right = s.slice(cursorIndex.value)
  const next = (left + str + right).slice(0, size.value)
  cursorIndex.value = Math.min(cursorIndex.value + str.length, size.value)
  emit('update:modelValue', next)
}
```

4. **空格显示**：空格在 HTML 中会折叠，用 `\u00A0`（不换行空格）占位显示；键盘显式拦截空格键插入空格（中文段落首行缩进场景）：

```js
function displayChar(c) { return c === ' ' ? '\u00A0' : (c || '') }
function onKey(e) {
  if (e.key === ' ') { e.preventDefault(); insert(' '); return }
  switch (e.key) {
    case 'Backspace': /* 删除光标前一字符 */ ...
    case 'ArrowLeft': cursorIndex.value--; ...
    case 'ArrowRight': cursorIndex.value++; ...
    case 'Enter': insert('\n'); ...   // 换行（渲染为换格/换行）
  }
}
```

5. **每 100 字标记**：右侧 `mark-column` 绝对定位显示 `▲100` 等：

```html
<div class="mark" :style="{ top: (m / PER_ROW) * ROW_H + 'px' }">▲{{ m }}</div>
```

### 4.3 材料标注功能

**位置**：`src/views/shenlun/index.vue`（会话级，退出不保留）

**功能**：在申论材料中选中文字 → 弹出工具条 → 可加**下划线 / 删除线 / 高亮**（黄/绿/红 3 色）；可清除单条或全部标注。

**核心实现**：

1. **标注数据模型**：按材料维护字符偏移区间数组：

```js
const anns = ref({}) // matId -> [{ s, e, style }]
const tb = ref({ show: false, x: 0, y: 0, matId: null, s: 0, e: 0 })
```

2. **标记标签映射**：

```js
const MARK_TAGS = {
  u: '<span style="text-decoration:underline">',
  s: '<span style="text-decoration:line-through">',
  y: '<span style="background:#fff59d">',
  g: '<span style="background:#c8e6c9">',
  r: '<span style="background:#ffcdd2">'
}
const MARK_ORDER = ['u', 's', 'y', 'g', 'r']  // 嵌套顺序固定，保证闭合
```

3. **渲染带标注的 HTML**（`markedHtml`）：构建「每字符样式集合」→ 顺序扫描，开/闭 span 标签：

```js
function markedHtml(m) {
  const text = m.content
  const list = (anns.value[m.id] || []).filter(a => a.s < a.e)
  if (!list.length) return text.replace(/&/g,'&amp;').replace(/</g,'&lt;').replace(/>/g,'&gt;').replace(/\n/g,'<br/>')
  if (text.includes('<img')) return text.replace(/\n/g, '<br/>') // 含图材料不标注
  const stylesAt = {}
  list.forEach(a => { for (let p = a.s; p < a.e; p++) { (stylesAt[p] = stylesAt[p] || new Set()).add(a.style) } })
  let out = '', open = []
  for (let i = 0; i < text.length; i++) {
    const st = stylesAt[i] || new Set()
    // 先关掉不再需要的标签，再按 MARK_ORDER 开新标签
    for (let k = open.length - 1; k >= 0; k--) if (!st.has(open[k])) { out += '</span>'; open.splice(k, 1) }
    MARK_ORDER.forEach(s => { if (st.has(s) && !open.includes(s)) { out += MARK_TAGS[s]; open.push(s) } })
    out += text[i] === '\n' ? '<br/>' : esc(text[i])
  }
  while (open.length) { out += '</span>'; open.pop() }
  return out
}
```

4. **选区转偏移**（`offsetIn`）：用 TreeWalker 遍历 DOM，把浏览器选区的 (节点, 偏移) 换算成材料纯文本中的字符偏移（`\n` 按 1 字符、`<br/>` 计 1 字符，与 content 索引一致）：

```js
function offsetIn(root, node, off) {
  const walker = document.createTreeWalker(root, NodeFilter.SHOW_TEXT | NodeFilter.SHOW_ELEMENT)
  let total = 0, br = 0, n
  while ((n = walker.nextNode())) {
    if (n.nodeType === Node.TEXT_NODE) { if (n === node) return total + off + br; total += n.textContent.length }
    else if (n.nodeName === 'BR') { if (n === node) return total + br + 1; br++ }
    else if (n === node) { /* 元素边界：累计前 offset 个子节点 */ ... }
  }
  return 0
}
```

```js
function onMatMouseUp(e, m) {
  const container = e.currentTarget  // 同步缓存，异步回调中 currentTarget 为 null
  setTimeout(() => {
    const sel = window.getSelection()
    if (!sel || sel.isCollapsed || !sel.rangeCount) { tb.value.show = false; return }
    const range = sel.getRangeAt(0)
    if (!container.contains(range.commonAncestorContainer)) { tb.value.show = false; return }
    const s = offsetIn(container, range.startContainer, range.startOffset)
    const e2 = offsetIn(container, range.endContainer, range.endOffset)
    if (s === e2) { tb.value.show = false; return }
    const rect = range.getBoundingClientRect()
    tb.value = { show: true, x: Math.min(rect.left + rect.width/2 - 120, window.innerWidth - 260), y: rect.bottom + 6, matId: m.id, s: Math.min(s,e2), e: Math.max(s,e2) }
  }, 30)
}
```

6. **应用/清除标注**：`applyMark(style)` 追加区间；`clearSel()` 删除当前区间；`clearMarks(matId)` 清空整篇。数据仅存内存 `anns`，**退出页面不保留**。

### request.js 关键处理

```js
// 若依全局默认 Content-Type 是 application/json，上传 FormData 时删除，
// 让浏览器自动带上 multipart boundary（否则后端报 "Current request is not a multipart request"）
service.interceptors.request.use(config => {
  if (config.data instanceof FormData) delete config.headers['Content-Type']
  return config
})
```
