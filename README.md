# 🐼 花花公考刷题（Huahuagongkao）

> 国考行测一站式刷题备考平台 —— 真题 · 教程 · 备考工具，全都有。

<img width="1369" height="838" alt="图片" src="https://github.com/user-attachments/assets/39f9078c-d796-4587-9127-cfc120322eab" />


基于 **RuoYi-Vue3 (v3.8.8)** 前后端分离框架搭建的国考行测刷题网站，内置 **2000-2022 年 36 套行测真题（4688 道题）**，配套完整答案解析、图片图表材料，并整合了「资料教程」「备考中心」「实时时政」等一条龙备考功能，从零基础小白到冲刺进阶都能用。

---

## ✨ 功能特性

### 📝 刷题中心

<img width="1370" height="839" alt="图片" src="https://github.com/user-attachments/assets/0e21f6a2-99cf-4c0a-9a76-ed305f8bcaef" />


- **试卷练习**：2000-2022 年共 36 套行测真题（A/B 卷、副省级、地市级、省级、市地级、行政执法类），按年筛选，显示每卷进度与正确率，支持断点续练
- **资料分析联动**：题目带共享材料时，左侧固定显示材料面板（文字/表格/图表图片），右侧逐题作答，材料始终可见；篇章阅读、组合排列的共享材料同样支持
- **随机练习**：按五大题型（常识/言语/数量/判断/资料）随机抽题
- **每日一练**：每天自动组卷 10 题（常识 2 + 言语 3 + 判断 2 + 数量 1 + 资料 2），即答即评，错题自动进错题本
- **逐题判分**：选择选项即提交，即时显示对错、正确答案与解析，答题卡可跳题
- **错题本**：错题汇总（我的答案/正确答案/解析/材料），可移出或清空

### 📚 资料模块（小白教程）

<img width="1369" height="841" alt="图片" src="https://github.com/user-attachments/assets/e5389b06-7068-4f8a-be15-381f30799d9b" />


- **11 篇完整教程**：备考总纲 + 国考行测五大模块 + 事业单位职测五大模块，每篇按"零基础概念 → 方法公式 → 真题例题逐步解析 → 易错点 → 进阶技巧 → 备考计划"编写
- **16 张教学配图**：行程示意图、容斥文氏图、图形推理规律、资料分析公式卡、百化分速记表、朝代时间轴等
- **视频课程目录**：B 站名师课程（聂佳判断推理、阿里木江言语、田鹏数量等）精选链接 + 搜索入口，链接均经有效性检测

### 🎯 备考中心

<img width="1366" height="844" alt="图片" src="https://github.com/user-attachments/assets/d9888741-ff32-4b84-8226-e4f3f756fcba" />


- **每日一练**：见刷题中心
- **学习计划**：90 天备考计划（12 周逐日任务），打卡进度可视化
- **成语积累**：110+ 高频/易错/易混成语（拼音/释义/例句），每日 10 个打卡式学习 + 测验模式
- **申论规范词**：8 大主题 110+ 组"大白话 → 规范词"对照 + 翻译练习
- **时政速递**：**央视《新闻联播》+ 央视快讯 + 新华社评论员实时资讯**（文字简讯卡片，自动抓取正文摘要）+ 36 道常考时政测验
- **速记卡片**：100 张公式口诀闪卡（资料/数量/判断/言语/常识/申论），翻卡记忆
- **申论素材**：8 大主题金句/事例/运用提示 + **16 篇高分范文（含"好在哪里"写作技法解析）** + **12 篇申论万能模板（换掉主题词即成文）** + 大作文模板与范文骨架
- **学习报告**：累计做题/正确率统计 + 各模块正确率条形图（自动定位薄弱模块）+ 各学习模块进度

### 🔧 管理功能

## 🚀 快速开始

### 环境依赖
| 组件 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 8 (Azul Zulu) | 后端运行 |
| Maven | 3.9.9 | 后端构建 |
| MySQL | 5.7.44 | 数据库（root/123456，库名 `ruoyi`） |
| Redis | 5.0.14 | 缓存 |
| Node.js | 24 | 前端构建与静态服务 |

### 一键启动
双击 `start-all.bat`（自动按需启动 MySQL / Redis / 后端 / 前端）。

### 访问
| 项目 | 地址 |
| --- | --- |
| 刷题网站 | http://127.0.0.1:8090 |
| 后端 API | http://127.0.0.1:8080 |
| 管理员账号 | admin / admin123（验证码已关闭） |

> `server.cjs` 同时代理 `/prod-api/**`（后端接口）、`/exam-img/**`（题库图片）与 `/news/**`（央视/新华社实时资讯）。

## 📁 项目结构

```
├── ruoyi/                 RuoYi-Vue3 前端
│   ├── src/views/practice/  刷题中心（试卷/随机/错题/每日一练）
│   ├── src/views/prep/      备考中心（8 大模块 + 数据文件）
│   ├── src/views/docs/      资料教程（11 篇 + 视频目录）
│   ├── src/views/exam/      题库管理
│   ├── public/docs/         教程教学配图
│   └── server.cjs           静态服务 + 代理（接口/图片/新闻）
├── ruoyi-backend/         RuoYi 后端
│   ├── ruoyi-system/        exam 题库模块（试卷/题目/材料/答题记录/统计）
│   └── ruoyi-admin/         ExamController、/exam-img 静态映射
├── tools/                 运维脚本（真题解析管线 parse_all.py / parse_sydw.py / gen_sql.py 等）
├── data/sql/               exam_schema.sql（表结构+菜单）、exam_data.sql（题库数据）
└── start-all.bat           一键启动脚本
```

## 🗄️ 数据与重建（可选）

题库由 Word 真题 + PDF 答案解析解析而来，可在本机重建：

```bash
python tools/parse_all.py all     # 重新解析国考行测（Word → JSON + 图片）
python tools/gen_sql.py           # 生成 data/sql/exam_data.sql
mysql -u root -p123456 ruoyi < data/sql/exam_data.sql
```

## ⚠️ 已知限制

- 个别旧卷（2002-2009）因 PDF 文本层损坏或扫描件，部分题目缺答案（可在题目管理中人工补全）
- 2002-B 卷答案 PDF 为纯扫描件，仅 OCR 出部分答案
- 部分年份的资料分析材料本身是整图（截图），直接以图片展示
- 题库目前为行测；申论试卷未入库（解析管线可扩展支持）
